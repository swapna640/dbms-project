## Overview
Our project uses a dataset from Zepto, found on Kaggle (link) on sample pizza sales. The schema consists of 4 tables : order_details.csv, orders.csv, pizza_types.csv, pizzas.csv. After extensive data cleaning and preprocessing, we worked on the basic ER model of the schema. Next, was the writing of the SQL queries, along with the equivalent statements in relational algebra and relational calculus. Finally, to make it come together at the end, we created a Java application to show the output in a presentable format.
